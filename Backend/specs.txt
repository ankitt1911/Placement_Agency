### 5. Request/Response Standards

**Success Response**:
```json
{
  "success": true,
  "message": "Profile updated successfully",
  "data": { ... },
  "statusCode": 200
}
```

**Paginated Response**:
```json
{
  "success": true,
  "total": 45,
  "page": 1,
  "limit": 10,
  "data": [],
  "statusCode": 200
}
```

**Error Response**:
```json
{
  "success": false,
  "message": "Validation failed",
  "statusCode": 422
}
```
